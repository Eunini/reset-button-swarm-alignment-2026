# Competitive review after the user's request for winning advice

November 5, 2026. This is pre-sprint preparation and an internal assessment, not a judge score or a prediction of placement.

## Verdict on the current entry

The current calibration prototype is not a convincing prize contender by itself. It is useful preparation, but it has no established novel result and does not yet execute interacting AI workers. Its three models act as monitors over constructed records. Two monitors solve all of the small pilot's graded views; the weaker monitor also has substantial output-format and complete-trace difficulties. Those observations do not demonstrate that a competent swarm safety system has been defeated.

There is no defensible numerical probability of winning: the competing submissions and judges' eventual decisions are unknown. More API calls or a better-looking document would not, on their own, fix the missing contribution.

These are examples of concrete contributions, not causal evidence of why any given judge awarded a prize.

## Changes to the execution standard

- Retain the quota pilot as calibration. Do not package it as a completed swarm experiment or a general failure of oversight.
- Anchor the substantive experiment in actual worker actions and independently checked outcomes. The research-evaluation integrity workflow in the main-study candidate is one feasible option, subject to a final related-work check.
- Keep a strong monitor that passes the ordinary/full-information task. A failure by an already incompetent checker is insufficient evidence for the intended safety claim.
- Isolate a meaningful variable: evidence visibility, source, or recovery access on the same executed workflow. Include clean and ambiguous cases, and disclose which comparisons receive more information.
- Test a proposed improvement on fresh cases and report the rate of blocking legitimate work. An always-stop strategy is a necessary negative control, not a useful win.
- Evaluate whether we have learned something a researcher could use: a new failure pattern, a better measured trade-off, or a reusable evaluation that exposes a previously hidden distinction. If not, change the question before expanding the study.
- Write around one plain-language claim, one main comparison figure, and the smallest set of experiments needed to support it. Treat clarity as part of the work; the entrant should be able to explain the project accurately.

## Decision gate before a larger run

Proceed with the substantive workflow only after identifying the exact difference from prior work, verifying labels, and confirming that the monitor can handle intact ordinary executions. Freeze the held-out test before seeing its outcomes. If the proposed failure disappears with a reasonable strong baseline, report that result and reassess; do not suppress it or weaken the baseline to obtain a dramatic finding.

The working topic remains provisional. This review does not authorize fabricated novelty, selective reporting, undisclosed prior work, or presenting preparation as work done during the sprint.
